# shadowblade linux
shadowblade linux is a linux distro using debian as a foundation to jumpstart the production of a full self maintained linux distro 
with it's own package manager and repo. shadowblade linux is maintained by a single person who grew up using linux.
my first ever computer was an old windows 95 computer that dualbooted redhat linux. i would mainly use redhat for everything.
fast forward to being an adult i decided i wanted to make my own linux distro my favorite distros are arch and void but i wanted
something to be easy to use and to work with. so it is using debian as a foundation and am slowly striping away any assets that includes 
debian's software so i can have a strong foundation. it is a distro designed for the community. i highly customizing your 
installation if you do not like anything that is preinstalled. discord will be posted soon.
